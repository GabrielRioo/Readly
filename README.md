# Leitor de Inglês

Leitor pessoal para praticar reading e listening. Os livros ficam neste aparelho.

## Uso

```bash
npm install
npm run dev
```

No celular ou tablet, abra o endereço da rede que o Vite mostrar. Em produção:

```bash
npm run build
npm run preview
```

O Chrome e o Safari podem oferecer “Instalar” para usar como app.

Formatos: EPUB, PDF com texto e TXT. Até 50 MB por arquivo.
